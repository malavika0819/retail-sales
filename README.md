# Retail Sales Management System

A full-stack Retail Sales Management application built using **React.js** for the frontend and **Spring Boot** for the backend. This project helps manage products, customers, billing, and sales operations efficiently.

## Features

- Product Management
- Customer Management
- Sales & Billing System
- REST API Integration
- Responsive UI
- CRUD Operations
- Secure Backend Architecture

## Tech Stack

### Frontend
- React.js
- HTML
- CSS
- JavaScript

### Backend
- Spring Boot
- Java
- Maven

### Database
- MySQL
